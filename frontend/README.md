# Front-end – Poliambulatorio Salus

Applicazione React + TypeScript (Vite) che usa l'API del back-end.

```bash
npm install
npm run dev      # server di sviluppo su http://localhost:5173
npm run lint     # analisi statica
npm run build    # controllo dei tipi e build di produzione
```

L'indirizzo dell'API si configura con `VITE_API_URL` (vedi `.env.example`).
Descrizione del progetto, architettura e istruzioni complete sono nel
[README principale](../README.md).
